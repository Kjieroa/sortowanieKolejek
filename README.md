# 📚 Kolejka w C++

> Prosty program w języku **C++** implementujący kolejkę za pomocą listy jednokierunkowej.

## ✨ Funkcjonalności

| Opcja | Opis |
|:---:|---|
| 📥 **1** | Wczytanie danych z pliku `dane.txt` |
| 🔄 **2** | Sortowanie kolejki metodą Bubble Sort |
| 👀 **3** | Wyświetlenie kolejki |
| 💾 **4** | Zapis kolejki do pliku `wynik.txt` |
| 🚪 **0** | Zakończenie programu |

## 🛠️ Wykorzystane technologie

- **C++**
- Lista jednokierunkowa
- Wskaźniki
- Klasy i struktury
- Dynamiczna alokacja pamięci
- Obsługa plików (`ifstream`, `ofstream`)
- Algorytm **Bubble Sort**
